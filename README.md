# Grok Bot Galaxy

X Broadcast「Grok Bot Galaxy」の読み物 Recap。Day 1〜3。

会話の断片や時刻印付きメモを並べるのではなく、**誰が何を主張し、何が決まり、何が未決のまま残ったか**が分かる記事です。スクリーンショットは話題の近くに少数だけ差し込みます。事実は元ノートの範囲に限り、聞き取れなかった箇所は埋めません。

各日の記事は次の型です（Day 1 済み。Day 2 / Day 3 も同じ型に揃える）。

1. ソース情報（broadcast、長さ、欠測方針）
2. この日の結論（先に読む）
3. 登場人物
4. 各場面：この場面 → 誰の主張 → 決まったこと／残ったこと
5. 読み返し用の結論

GitHub 上で `.html` を開くとソース表示になる。ブラウザで読むには GitHub Pages を使う。ローカルなら各日の `index.html` を開く。

**Pages は public リポジトリでのみ公開できる**（このアカウントの `codex-harnesses` と同じ）。private のままだと Deploy GitHub Pages はサイトを作れない。

公開手順:
1. Settings → General → Danger zone → **Change visibility** → Public
2. Actions の [Deploy GitHub Pages](https://github.com/s-hiraoku/grok-bot-galaxy/actions/workflows/pages.yml) を Re-run
